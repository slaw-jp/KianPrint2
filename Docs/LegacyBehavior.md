## 標準裁判書式

| 項目 | 実測値 |
|---|---:|
| 用紙 | A4（210 × 297mm） |
| フォント | Hiragino Mincho ProN W3 |
| 本文文字サイズ | 12pt |
| 上余白 | 35mm |
| 下余白 | 27mm |
| 左余白 | 30mm |
| 右余白 | 22mm |
| 字間 | 0pt |
| 段落の追加行間 | 13.62pt |

KianPrint2では、front matterがない場合または `プリセット: 裁判所` を指定した場合だけ、これらの標準値と横37字・縦26行の制御を使う。プリセットと併記された他の設定はすべて無視する。同じ数値を手動指定してもプリセットは発動しない。横幅は37emに切り詰めず、先代と同じ余白由来の約447.87pt（37.323em）を使う。これにより38個目の全角文字は入らない一方、約0.323字分の余裕を半角文字や約物の実測幅に利用する。縦は本文高を26等分し、見出しも含めて各1行分の縦幅を占める。

旧実装のコメントでは右余白の本来値を20mmとしつつ、右揃え行の見え方を調整するため22mmを採用している。KianPrint2の互換デフォルトは実際に使われていた22mmとする。

ページ番号は本文領域の横中央、下余白の縦中央へ、本文より1pt小さい文字で算用数字のみを表示する。単一ページだけなら省略し、複数ページまたは明示的改ページがあれば全ページに表示する。

明示的改ページは、独立行の `【改ページ】` で文書を分割する。

## 法律文書番号体系

字下げ量は本文フォントサイズを1単位とする。`第n条` または `第n　` が文書内にあるときは下表の値を使い、ない文書では各段階から1単位引く。

| 先頭パターン | 本文字下げ | 先頭行の戻し |
|---|---:|---:|
| `第１条` | 2 | 2 |
| `第１　` | 2 | 2 |
| `１　` | 2 | 1 |
| `１(1)　` | 3 | 2 |
| `(1)　` | 3 | 1 |
| `(1)ア　` | 4 | 2 |
| `ア　` | 4 | 1 |
| `ア(ア)　` | 5 | 2 |
| `(ア)　` | 5 | 1 |
| `(ア)ａ　` | 6 | 2 |
| `ａ　` | 6 | 1 |
| `ａ(a)　` | 7 | 2 |
| `(a)　` | 7 | 1 |

数字は該当箇所では全角、丸括弧内部では半角。片仮名は `ア-ン`、英字は全角 `ａ-ｚ` と半角括弧内 `a-z` を認識する。

丸数字 `①-⑳` は直前段落より1段深くし、連続する丸数字同士は同じ段階を維持する。

全角空白2字で始まる非空行は継続段落である。原則として直前段落の本文字下げを継承し、先頭行だけ1字戻す。丸数字列の直後は、直近の丸数字でない段落まで遡ってその字下げを継承する。

## 旧式の配置・見出し

行頭と行末の全角空白数で次を認識する。内容から両端の空白を除いて描画する。

| 行頭 / 行末 | 配置 | サイズ |
|---|---|---:|
| 5字 / 5字 | 中央 | 本文の1.5倍（本文12pt時は18pt） |
| 4字 / 4字 | 中央 | 本文の4/3倍（本文12pt時は16pt） |
| 3字 / 3字 | 中央 | 本文の7/6倍（本文12pt時は14pt） |
| 2字 / 2字 | 中央 | 本文と同じ |
| 2字 / 1字 | 右 | 本文と同じ |

KianPrint2は互換入力としてこれらを受け付けるが、新文書ではMarkdown見出し、`@中央揃え`、`@右揃え`、`@右配置` を推奨する。職印を押す代理人表示では、本文右端に30mmを空ける `@右揃え(職印)` または `@右配置(職印)` を使える。

先代の番号認識は丸括弧内の算用数字だけ半角を前提としていた。KianPrint2では実際の法律文書の入力に合わせ、同じ階層について全角数字・全角括弧（例: `（１）`）を標準形として追加し、先代形式も互換入力として残す。

## 既存PDF動作とKianPrint2での変更

既存KianPrintはTextKitの `NSTextStorage`、`NSLayoutManager`、`NSTextContainer` で改行とページ分割を行い、一時PDFをPreview.appで開く。KianPrint2は値と番号規則のみ互換にし、改行を独自の `KianLineBreaker`、描画をCore Text / Core Graphics、プレビューをアプリ内ベクター描画へ置き換える。
