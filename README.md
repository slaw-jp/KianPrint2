# KianPrint2

KianPrint2は、プレーンテキストを日本の裁判・法律実務向けA4文書として組版するmacOSアプリです。原稿は `mi.app` などのテキストエディタで編集し、KianPrint2がライブプレビューとPDF出力を担当します。

現在のβ版は `0.3.0-beta.1` です。アプリの `CFBundleShortVersionString` は `0.3.0`、リリースタグは `v0.3.0-beta.1` です。入力文法と出力結果が今後変更される可能性があります。

## 主な機能

- `.txt` を日本語の文章へ書き足しやすいKianPrint2独自記法として解釈
- Core Textの実測幅と独自の日本語禁則処理で改行
- 裁判所プリセットの37字×26行組版
- 先代KianPrint互換の法律文書番号・ぶら下がりインデント
- 行末指定による揃え・絶対文字サイズ、行内強調、タブ配置、明示的改ページ
- 本文文字サイズ単位で列幅を指定できる汎用表
- 当事者目録などを読みやすいTab区切りで配置できる、列幅指定のタブ配置
- 複数A4ページのベクタープレビューとPDF出力
- 保存の自動再読み込みと、エラー時の直前プレビュー保持

## ダウンロードとインストール

動作環境はmacOS 13以降のApple Silicon MacまたはIntel Macです。GitHubのReleasesから `KianPrint2-0.3.0-beta.1-macOS-universal.zip` をダウンロードして展開し、`KianPrint2.app` を「アプリケーション」フォルダへ移動してください。

このβ版はDeveloper ID署名とAppleのnotarizationをまだ行っていません。初回起動時にmacOSが開発元を確認できない旨を表示した場合は、配布元とファイルが正しいことを確認したうえで、一度起動を試してから「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選択します。将来のリリースではDeveloper ID署名とnotarizationの導入を予定しています。

不具合はGitHub Issuesへ、セキュリティ上の問題は[SECURITY.md](SECURITY.md)の方法で報告してください。

## 基本ワークフロー

1. Finderまたはmi.appで `.txt` を開きます。
2. mi.appのToolから保存してKianPrint2へ渡します。
3. 以後は保存するたびにプレビューが更新されます。
4. 必要なときに「PDFを書き出す」を実行します。

mi.appのToolには次の形式を利用できます。

```text
<<<SAVE DROP(KianPrint2.app)>>>
```

一般のMarkdown `.md` を別のエディタに関連付けたまま使えるよう、入力拡張子は意図的に `.txt` としています。

## 書式設定と裁判所プリセット

設定はファイル先頭の `---` で囲んだfront matterに記載します。区切りはハイフン3個です。

### 37字×26行の発動条件

次のどちらかだけで裁判所プリセットが発動します。

1. front matterをまったく書かない（空のfront matterも同じ）。
2. `preset: court` を指定する。

```text
---
preset: court
---
```

裁判所プリセットがあると、同じブロックの他の項目は記載順にかかわらずすべて無視され、次の値に固定されます。

| 設定名 | 値 |
|---|---:|
| `paper` | A4（210×297mm） |
| `font` | Hiragino Mincho ProN W3 |
| `font-size` | 12pt |
| `top` | 35mm |
| `bottom` | 27mm |
| `left` | 30mm |
| `right` | 22mm |
| `kern` | 0pt |
| `spacing` | 13.62pt |
| `page-number` | on |
| `kinsoku` | court |

横は先代KianPrintと同じ余白由来の約447.87pt（37.323全角字相当）を使います。全角38字目は入らず、約0.323字分の余裕は半角文字や約物に使われます。縦は本文高を26等分します。`@size` で指定した文字が標準の行高を超える場合は、文字が重ならないよう必要な高さを確保します。

値を手動ですべて同じにしても、`preset: court` がなければ37字×26行の制御は発動しません。`@size` を指定した行は文字サイズに応じた高さを使い、行数は保証されません。

```text
---
font-size: 12pt
top: 35mm
bottom: 27mm
left: 30mm
right: 22mm
kern: 0pt
spacing: 13.62pt
page-number: on
kinsoku: court
---
```

### 手動設定

front matterに一つでも設定があり、裁判所プリセットがない場合は手動書式です。書かなかった項目の初期値は裁判所書式と同じですが、37字×26行は保証されません。

| 設定名 | 形式 | 説明 |
|---|---|---|
| `paper` | `A4` | β版はA4のみ |
| `font` | フォント名 | macOSの本文フォント名 |
| `font-size` | `12pt` | 本文文字サイズ |
| `top` `bottom` `left` `right` | `20mm` | 各余白 |
| `kern` | `0pt` | 先代のKernに相当 |
| `spacing` | `6pt` | 文字サイズへ追加する間隔 |
| `page-number` | `on` / `off` | 複数ページ時の表示 |
| `kinsoku` | `court` | β版の日本語禁則規則 |

一般書面の例です。

```text
---
font-size: 12pt
kern: 0pt
spacing: 6pt
top: 25mm
bottom: 25mm
---
```

この行送りは12pt＋6pt＝18ptです。空行もこの文書の行送り1行分を占めます。繰り返し使う書式は、mi.appのToolにfront matterを定型文として登録すると便利です。

## 法律文書の原稿作法

本文では、段落と段落の間に空行を入れません。空行は実際の1行として組版されるので、原稿に書けばその分だけ縦位置が下がります。年、月、日、事件番号、金額、項番号、号証番号など、法律文書本文の数字は原則として全角で書きます。証拠説明書の表内の日付だけは実務上の例外として `R8.4.1` のように半角で書けます。

```text
第１　請求の原因
１　当事者
　　原告は、文房具の販売等を業とする株式会社である。
２　売買契約
　　原告と被告は、令和８年４月１日、売買契約を締結した。
```

## KianPrint2独自記法

原稿をプレーンテキストのまま読みやすくし、日本語入力中でもTabキーと行末への短い指定だけで書式を付けられることを優先しています。Markdownの見出し、引用、パイプ表は解釈しません。`#`、`>`、`<br>` は通常の文字として表示します。行内の `**太字**` と `*斜体*` だけは引き続き使用できます。

### 行末の配置と文字サイズ

行の末尾へ、改行を入れる直前に指定します。指定自体は印刷されません。

```text
以上@right
原告訴訟代理人弁護士　架　空　次　郎@right(36)
記@center
附属書類@center@size(24)
弁護士　架　空　太　郎　殿@size(20)
```

- `@right` は本文領域の右端へ揃えます。
- `@right(36)` は右端に36ptの余白を確保して右揃えします。折り返した各行にも同じ余白が適用されます。
- `@center` は本文領域の中央へ揃えます。
- `@size(24)` はその行を絶対値24ptで表示します。本文サイズに対する倍率ではありません。
- 配置とサイズは `@center@size(24)` のように併用でき、順序は問いません。

`@right` と `@center` は同じ行に併用できません。`@右配置` は復活させず、複数欄の配置には `@tab` を使います。

### 行内強調

```text
**太字**
*斜体*
**太字の中に *斜体* を入れる**
```

太字は本文フォントにかかわらずHiragino Sans W6で表示し、斜体は本文フォントのitalic traitを使います。通常行、表セル、タブ配置内で使用できます。それ以外のMarkdown記法は解釈しません。

### 表

`@table` の括弧内に列幅を書き、閉じ括弧の直後から各列の配置をTab区切りで宣言します。次の行からデータを書き、各セルもTabで区切ります。最終データ行の末尾へ `@end` を付けます。

```text
@table(4,8,3,6,6,10)center	center	center	center	center	left
符号番号	標目		作成年月日	作成者	立証趣旨
center	left	center	center	left	left
甲１	商品売買契約書	原本	R8.4.1	原告及び被告	本件売買契約が成立したこと@end
```

列幅の1単位は本文の `font-size` と同じpt数です。本文12ptで幅4なら48pt、本文15ptなら60ptです。表全体は左へ配置され、幅の合計が本文幅より狭くても拡大しません。

配置は `left`、`center`、`right` のいずれかです。配置宣言が列数より少なければ残りは `left`、多ければ超過分は無視します。データセルが列数より少なければ右側を空セルで埋め、列数より多ければ行番号付きエラーにします。配置だけを書いた行を途中へ挟むと、それ以後の行の配置を何度でも変更できます。

Tabの前後を含む半角・全角空白は削除せず、その幅も含めて描画します。セル内の文字は罫線から左右3pt離して配置します。太字と斜体も使用できます。

通常は1行目を表見出しとして扱い、改ページ後のページ冒頭へ再描画します。見出し扱いをなくす場合だけ `puretable` を指定します。

```text
@table(8,12;puretable)left	right
項目	数量@end
```

### タブ配置

`@tab` は罫線を描かない表です。開始、列幅、配置、Tabによるセル区切り、途中の配置変更、空白の保持、セル数の検査、行末の `@end` は `@table` と同じです。

```text
@tab(6,6)left	right
訴訟物の価額	１０００万円
貼用印紙額	１００万円@end
```

各欄は指定幅の中で左・中央・右へ揃えられます。収まらない文字は同じ欄の中で折り返し、折返しの最終行が1文字だけになる場合は直前の文字も最終行へ送ります。空欄を置く場合は連続するTabも省略しないでください。

当事者目録で先頭10字分を空け、その後へ役割と名称を置く例です。

```text
当事者目録@center@size(18)
@tab(10,11,16)left	left	left
〒０００－００００	架空県架空市１丁目１番１号
	原　告	株式会社架空商事
	上記代表者代表取締役	架　空　花　子@end
```

### 改ページ

`@page` の独立行で明示的に改ページします。

```text
@page
```

KianPrint2で以前使われていた `{` と `}` で囲む `@table`／`@tab`、Markdownのパイプ表はエラーになります。`@end` の独立行も受け付けません。

## 法律文書の番号とインデント

番号部分は左へ出し、折返しは本文開始位置に揃えます。字下げの1単位は本文文字サイズです。

| 先頭パターン | 本文字下げ | 先頭行の戻し |
|---|---:|---:|
| `第１条` | 2 | 2 |
| `第１　` | 2 | 2 |
| `１　` | 2 | 1 |
| `１(1)　` | 3 | 2 |
| `(1)　` | 3 | 1 |
| `(1)ア　` | 4 | 2 |
| `ア　` | 4 | 1 |
| `ア(ア)　` | 5 | 2 |
| `(ア)　` | 5 | 1 |
| `(ア)ａ　` | 6 | 2 |
| `ａ　` | 6 | 1 |
| `ａ(a)　` | 7 | 2 |
| `(a)　` | 7 | 1 |

番号体系は先代KianPrintと同じです。外側の番号は全角数字、丸括弧は半角、丸括弧内の算用数字は半角で書きます。`（１）` のような全角括弧・全角数字は階層記号として扱いません。`第１条` または `第１　` で始まる段落が文書中にない場合は、各階層の本文字下げから1単位を引きます。`①`～`⑳` は直前段落より1段深くし、連続する丸数字は同じ深さにします。全角空白2字で始まる非空行は継続段落として、原則として直前段落の本文インデントを引き継ぎます。

## ページ分割とページ番号

- 本文は行送りを積み上げ、下余白に入る前に次ページへ送ります。
- `@size` を指定した行は文字が重ならない行高を確保します。
- 表は行単位で分割し、通常の `@table` は1行目を再表示します。`puretable` では再表示しません。
- ページ番号は本文領域の横中央、下余白の縦中央に表示します。
- 1ページだけの文書では表示しません。複数ページまたは明示的改ページがあると全ページに表示します。

## 先代KianPrintの互換記法

行の両端に全角空白を置く先代KianPrintの記法も読み込みます。新規文書では `@center`、`@right`、`@size` を行末に使います。特に、行頭に全角空白2字、行末に1字を置く `　　以上　` は後方互換のため引き続き右揃えとして扱います。

| 行頭 / 行末の全角空白 | 表示 |
|---|---|
| 5字 / 5字 | 中央、18pt |
| 4字 / 4字 | 中央、16pt |
| 3字 / 3字 | 中央、14pt |
| 2字 / 2字 | 中央、12pt |
| 2字 / 1字 | 右揃え、12pt |

## エラーと警告

- front matterの不正な数値、未知のプリセット、閉じる `---` や `@end` の欠落は行番号付きエラーです。
- 旧KianPrint2形式の表・タブ配置、独立行の `@end`、列幅より多い内容セルは行番号付きエラーです。
- 未知の設定名は警告して無視します。
- エラーがある間も直前の正常なプレビューを残します。
- `preset: court` があると、preset以外の項目は評価されず無視されます。

## ビルドとテスト

必要環境はmacOS 13以降とXcodeです。外部パッケージへのネットワークアクセスは不要です。貢献方法は[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。

```sh
xcodebuild -project KianPrint2.xcodeproj -scheme KianPrint2 \
  -configuration Release SYMROOT=$PWD/build build

cd Packages/KianPrintCore
swift test
```

出力は `build/Release/KianPrint2.app`、署名はad-hocです。詳細は [`Docs/Releasing.md`](Docs/Releasing.md) を参照してください。
