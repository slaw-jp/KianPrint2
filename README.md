# KianPrint2

KianPrint2は、プレーンテキストを日本の裁判・法律実務向けA4文書として組版するmacOSアプリです。「第１　」「１　」「(1)　」などのナンバリングをアプリが読み取って自動でインデントを付けます。MS Word等は介さず、いきなり紙面を描画し、PDFを生成します。そのため、法律家がワープロソフトで最低限やるようなことはだいたいできるようにしたつもりです。

現在のβ版は `0.3.0-beta.1` です。アプリの `CFBundleShortVersionString` は `0.3.0`、リリースタグは `v0.3.0-beta.1` です。入力文法と出力結果が今後変更される可能性があります。

なお、改善提案は受け付けておりません。文書の書き方は弁護士それぞれだからです。改善したい人はここのソースコードをLLMに見せて自分用のものを作らせると良いです。

## 主な機能

- アプリがプレーンテキストだけからナンバリングを読み取って自動でインデント
- 日本語の文章の流れをなるべく壊さないKianPrint2独自記法で組版
- プリセット任せで判決書形式の字数・行数・余白、禁則処理
- 行末指定による揃え・絶対文字サイズ、行内強調、タブ配置、明示的改ページ
- 本文文字サイズ単位で列幅を指定できる汎用表
- 当事者目録などを読みやすいTab区切りで配置できる、列幅指定のタブ配置
- 複数A4ページのベクタープレビューとPDF出力
- テキストエディタで保存したらKianPrint2の描画に即反映（描画結果を見ながらテキストを書ける）

## ダウンロードとインストール

動作環境はmacOS 13以降のApple Silicon MacまたはIntel Macです。GitHubのReleasesから `KianPrint2-0.3.0-beta.1-macOS-universal.zip` をダウンロードして展開し、`KianPrint2.app` を「アプリケーション」フォルダへ移動してください。

このβ版はDeveloper ID署名とAppleのnotarizationをまだ行っていません。初回起動時にmacOSが開発元を確認できない旨を表示した場合は、配布元とファイルが正しいことを確認したうえで、一度起動を試してから「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選択します。

## 基本ワークフロー

1. テキストエディタで`.txt` を開きます。
2. KianPrint2でも同時に開きます。
3. 以後はテキストエディタで保存するたびにKianPrint2の描画が更新されます。
4. 必要なときに「PDFを書き出す」を実行します。

作者は弁護士仕事の起案用テキストエディタとしてmi.appをずっと愛用しています。mi.appのToolに文字列を入れればmi.appからKianPrint2に直接.txtを送れます。
```text
<<<SAVE DROP(KianPrint2.app)>>>
```

## 書式設定と裁判所プリセット

設定はファイル先頭の `---` で囲んだfront matterに記載します。区切りはハイフン3個です。

### 37字×26行の発動条件

次のどちらかだけで裁判所プリセットが発動します。

1. front matterをまったく書かない（空のfront matterも同じ）。
2. `preset: court` を指定する。

```text
---
preset: court
---
```

裁判所プリセットがあると、同じブロックの他の項目は記載順にかかわらずすべて無視され、次の値に固定されます。

| 設定名 | 値 |
|---|---:|
| `paper` | A4（210×297mm） |
| `font` | Hiragino Mincho ProN W3 |
| `font-size` | 12pt |
| `top` | 35mm |
| `bottom` | 27mm |
| `left` | 30mm |
| `right` | 22mm |
| `kern` | 0pt |
| `spacing` | 13.62pt |
| `page-number` | on |
| `kinsoku` | court |

この設定では、横は約447.87pt（37.323全角字相当）を文字描画領域として使います。全角38字目は入らず、約0.323字分の余裕は半角文字や約物に使われます。縦は本文高を26等分します。`@size` で指定した文字が標準の行高を超える場合は、文字が重ならないよう必要な高さを確保します。

値を手動ですべて同じにしても、`preset: court` がなければ37字×26行の制御は発動しません。`@size` を指定した行は文字サイズに応じた高さを使い、行数は保証されません。

```text
---
font-size: 12pt
top: 35mm
bottom: 27mm
left: 30mm
right: 22mm
kern: 0pt
spacing: 13.62pt
page-number: on
kinsoku: court
---
```

### 手動設定

front matterに一つでも設定があり、裁判所プリセットがない場合は手動書式です。書かなかった項目の初期値は裁判所書式と同じですが、37字×26行は保証されません。

| 設定名 | 形式 | 説明 |
|---|---|---|
| `paper` | `A4` | β版はA4のみ |
| `font` | フォント名 | macOSの本文フォント名 |
| `font-size` | `pt` | 本文文字サイズ |
| `top` `bottom` `left` `right` | `mm` | 各余白 |
| `kern` | `pt` | 文字間隔の設定 |
| `spacing` | `pt` | 行間隔の設定 |
| `page-number` | `on` / `off` | 複数ページ時の表示 |
| `kinsoku` | `court` | 判決書模倣日本語禁則規則。選択肢は一つ。 |

一般書面の例です。

```text
---
font-size: 12pt
kern: 0pt
spacing: 6pt
top: 25mm
bottom: 25mm
---
```

## KianPrint2独自記法

原稿をプレーンテキストのまま読みやすくし、日本語入力中でもTabキーと行末への短い指定だけで書式を付けられることを優先しています。Markdownは `**太字**` と `*斜体*` だけ使えます。太字は本文フォントにかかわらずHiragino Sans W6。

### 行末の配置と文字サイズ

行の末尾へ、改行を入れる直前に指定します。指定自体は印刷されません。

```text
以上@right
原告訴訟代理人弁護士　架　空　次　郎@right(36)
記@center
附属書類@center@size(24)
弁護士　架　空　太　郎　殿@size(20)
```

- `@right` は本文領域の右端へ揃えます。
- `@right(36)` は右端に36ptの余白を確保して右揃えします。折り返した各行にも同じ余白が適用されます。
- `@center` は本文領域の中央へ揃えます。
- `@size(24)` はその行を絶対値24ptで表示します。本文サイズに対する倍率ではありません。
- 配置とサイズは `@center@size(24)` のように併用でき、順序は問いません。

`@right` と `@center` は同じ行に併用できません。

### 表

`@table` の括弧内に列幅を書き、閉じ括弧の直後から各列の配置をTab区切りで宣言します。次の行からデータを書き、各セルもTabで区切ります。最終データ行の末尾へ `@end` を付けます。

```text
@table(4,8,3,6,6,10)center	center	center	center	center	left
符号番号	標目		作成年月日	作成者	立証趣旨
center	left	center	center	left	left
甲１	商品売買契約書	原本	R8.4.1	原告及び被告	本件売買契約が成立したこと@end
```

列幅の1単位は本文の `font-size` と同じpt数です。本文12ptで幅4なら48pt、本文15ptなら60ptです。表全体は左へ配置され、幅の合計が本文幅より狭くても拡大しません。

配置は `left`、`center`、`right` のいずれかです。配置宣言が列数より少なければ残りは `left`、多ければ超過分は無視します。データセルが列数より少なければ右側を空セルで埋め、列数より多ければ行番号付きエラーにします。配置だけを書いた行を途中へ挟むと、それ以後の行の配置を何度でも変更できます。

配置はそこから下の行に効きます。どこからでも再び宣言できます。

Tabの前後を含む半角・全角空白は削除せず、その幅も含めて描画します。セル内の文字は罫線から左右3pt離して配置します。太字と斜体も使用できます。

通常は1行目を表見出しとして扱い、改ページ後のページ冒頭へ再描画します。見出し扱いをなくす場合だけ `puretable` を指定します。

```text
@table(8,12;puretable)left	right
項目	数量@end
```

### タブ配置

`@tab` は罫線を描かない表です。開始、列幅、配置、Tabによるセル区切り、途中の配置変更、空白の保持、セル数の検査、行末の `@end` は `@table` と同じです。

```text
@tab(6,6)left	right
訴訟物の価額	１０００万円
貼用印紙額	１００万円@end
```

各欄は指定幅の中で左・中央・右へ揃えられます。収まらない文字は同じ欄の中で折り返し、折返しの最終行が1文字だけになる場合は直前の文字も最終行へ送ります。空欄を置く場合は連続するTabも省略しないでください。


### 改ページ

`@page` の独立行で明示的に改ページします。

```text
@page
```

`@end` の独立行は受け付けません。

## 法律文書の番号とインデント

ナンバリングの行だけスペースを空けずに書き始めます。それに続く行は全角スペース２つ入れて書き始めるとちょうど良いインデントになるようになっています。

番号部分は左へ出し、折返しは本文開始位置に揃えます。字下げの1単位は本文文字サイズです。

| 先頭パターン | 本文字下げ | 先頭行の戻し |
|---|---:|---:|
| `第１条` | 2 | 2 |
| `第１　` | 2 | 2 |
| `１　` | 2 | 1 |
| `１(1)　` | 3 | 2 |
| `(1)　` | 3 | 1 |
| `(1)ア　` | 4 | 2 |
| `ア　` | 4 | 1 |
| `ア(ア)　` | 5 | 2 |
| `(ア)　` | 5 | 1 |
| `(ア)ａ　` | 6 | 2 |
| `ａ　` | 6 | 1 |
| `ａ(a)　` | 7 | 2 |
| `(a)　` | 7 | 1 |

外側の番号は全角数字、丸括弧は半角、丸括弧内の算用数字は半角で書きます。`（１）` のような全角括弧・全角数字は階層記号として扱いません。`第１条` または `第１　` で始まる段落が文書中にない場合は、各階層の本文字下げから1単位を引きます。`①`～`⑳` は直前段落より1段深くし、連続する丸数字は同じ深さにします。全角空白2字で始まる非空行は継続段落として、原則として直前段落の本文インデントを引き継ぎます。

## ページ分割とページ番号

- 本文は行送りを積み上げ、下余白に入る前に次ページへ送ります。
- `@size` を指定した行は文字が重ならない行高を確保します。
- 表は行単位で分割し、通常の `@table` は1行目を再表示します。`puretable` では再表示しません。
- ページ番号は本文領域の横中央、下余白の縦中央に表示します。
- 1ページだけの文書では表示しません。複数ページまたは明示的改ページがあると全ページに表示します。

## 先代KianPrintの互換記法

作者のブログにある先代KianPrintに対する後方互換性が今のところあります。
| 行頭 / 行末の全角空白 | 表示 |
|---|---|
| 5字 / 5字 | 中央、18pt |
| 4字 / 4字 | 中央、16pt |
| 3字 / 3字 | 中央、14pt |
| 2字 / 2字 | 中央、12pt |
| 2字 / 1字 | 右揃え、12pt |

## エラーと警告

- front matterの不正な数値、未知のプリセット、閉じる `---` や `@end` の欠落は行番号付きエラーです。
- 独立行の `@end`、列幅より多い内容セルは行番号付きエラーです。
- 未知の設定名は警告して無視します。
- エラーがある間も直前の正常なプレビューを残します。
- `preset: court` があると、preset以外の項目は評価されず無視されます。

## ビルドとテスト

必要環境はmacOS 13以降とXcodeです。外部パッケージへのネットワークアクセスは不要です。

```sh
xcodebuild -project KianPrint2.xcodeproj -scheme KianPrint2 \
  -configuration Release SYMROOT=$PWD/build build

cd Packages/KianPrintCore
swift test
```

出力は `build/Release/KianPrint2.app`、署名はad-hocです。詳細は [`Docs/Releasing.md`](Docs/Releasing.md) を参照してください。

## 沿革

KianPrint2はこの思想を、macOSアプリとして洗練させた形で実装し、プレーンテキストで読みやすい独自記法、独自組版、表をも備えるに至った後継プロジェクトです。
