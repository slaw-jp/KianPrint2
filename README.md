# KianPrint2

KianPrint2は、プレーンテキストを日本の裁判・法律実務向けA4文書として組版するmacOSアプリです。原稿は `mi.app` などのテキストエディタで編集し、KianPrint2がライブプレビューとPDF出力を担当します。

β版は `0.1.0-beta.1` です。アプリの `CFBundleShortVersionString` は `0.1.0`、リリースタグは `v0.1.0-beta.1` です。

## 主な機能

- `.txt` をKian Markdown（Markdownの限定部分＋日本語Directive）として解釈
- Core Textの実測幅と独自の日本語禁則処理で改行
- 裁判所プリセットの37字×26行組版
- 先代KianPrint互換の法律文書番号・ぶら下がりインデント
- 見出し、強調、引用、揃え、明示的改ページ
- 12pt文字単位で列幅を指定できる汎用表と罫線なし表
- 当事者目録などをスペースなしで配置できる文字単位のタブ位置
- 複数A4ページのベクタープレビューとPDF出力
- 保存の自動再読み込みと、エラー時の直前プレビュー保持

## 基本ワークフロー

1. Finderまたはmi.appで `.txt` を開きます。
2. mi.appのToolから保存してKianPrint2へ渡します。
3. 以後は保存するたびにプレビューが更新されます。
4. 必要なときに「PDFを書き出す」を実行します。

mi.appのToolには次の形式を利用できます。

```text
<<<SAVE DROP(KianPrint2.app)>>>
```

Markdown一般の `.md` を別のエディタに関連付けたまま使えるよう、入力拡張子は意図的に `.txt` としています。

## 書式設定と裁判所プリセット

設定はファイル先頭の `---` で囲んだfront matterに記載します。区切りはハイフン3個です。

### 37字×26行の発動条件

次のどちらかだけで裁判所プリセットが発動します。

1. front matterをまったく書かない（空のfront matterも同じ）。
2. `プリセット: 裁判所` を指定する。

```text
---
プリセット: 裁判所
---
```

裁判所プリセットがあると、同じブロックの他の項目は記載順にかかわらずすべて無視され、次の値に固定されます。

| 項目 | 値 |
|---|---:|
| 用紙 | A4（210×297mm） |
| フォント | Hiragino Mincho ProN W3 |
| 文字サイズ | 12pt |
| 上余白 | 35mm |
| 下余白 | 27mm |
| 左余白 | 30mm |
| 右余白 | 22mm |
| 字間（Kern） | 0pt |
| 行間（Line Spacing） | 13.62pt |
| ページ番号 | あり |
| 禁則処理 | 裁判所 |

横は先代KianPrintと同じ余白由来の約447.87pt（37.323全角字相当）を使います。全角38字目は入らず、約0.323字分の余裕は半角文字や約物に使われます。縦は本文高を26等分し、大きな見出しも1行分の高さとして数えます。

値を手動ですべて同じにしても、`プリセット: 裁判所` がなければ37字×26行の制御は発動しません。見出しは文字サイズに応じた高さを使い、行数は保証されません。

```text
---
文字サイズ: 12pt
上余白: 35mm
下余白: 27mm
左余白: 30mm
右余白: 22mm
字間: 0pt
行間: 13.62pt
ページ番号: あり
禁則処理: 裁判所
---
```

### 手動設定

front matterに一つでも設定があり、裁判所プリセットがない場合は手動書式です。書かなかった項目の初期値は裁判所書式と同じですが、37字×26行は保証されません。

| 設定名 | 形式 | 説明 |
|---|---|---|
| `用紙` | `A4` | β版はA4のみ |
| `フォント` | フォント名 | macOSのフォント名 |
| `文字サイズ` | `12pt` | 本文文字サイズ |
| `上余白` `下余白` `左余白` `右余白` | `20mm` | 各余白 |
| `字間` | `0pt` | 先代のKernに相当 |
| `行間` | `6pt` | 文字サイズへ追加する間隔 |
| `ページ番号` | `あり` / `なし` | 複数ページ時の表示 |
| `禁則処理` | `裁判所` | β版の日本語禁則規則 |

一般書面の例です。

```text
---
文字サイズ: 12pt
字間: 0pt
行間: 6pt
上余白: 25mm
下余白: 25mm
---
```

この行送りは12pt＋6pt＝18ptです。空行もこの文書の行送り1行分を占めます。繰り返し使う書式は、mi.appのToolにfront matterを定型文として登録すると便利です。

## 法律文書の原稿作法

本文では、段落と段落の間に空行を入れません。空行は実際の1行として組版されるので、原稿に書けばその分だけ縦位置が下がります。年、月、日、事件番号、金額、項番号、号証番号など、法律文書本文の数字は原則として全角で書きます。証拠説明書の表内の日付だけは実務上の例外として `R8.4.1` のように半角で書けます。

```text
第１　請求の原因
１　当事者
　　原告は、文房具の販売等を業とする株式会社である。
２　売買契約
　　原告と被告は、令和８年４月１日、売買契約を締結した。
```

## 対応するMarkdown記法

KianPrint2はMarkdown全体ではなく、次の記法だけを解釈します。

### 見出し

| 記法 | 裁判所プリセットでの表示 |
|---|---|
| `# 見出し` | 中央、18pt |
| `## 見出し` | 中央、16pt |
| `### 見出し` | 中央、14pt |
| `#### 見出し` | 中央、12pt |

`#`と見出し文の間に半角空白が必要です。サイズは先代KianPrintと同じく本文サイズに対する倍率で、順に1.5倍、4/3倍、7/6倍、1倍です。したがって本文が12ptなら18／16／14／12pt、本文が15ptなら22.5／20／17.5／15ptになります。

### 行内強調

```markdown
**太字**
*斜体*
**太字の中に *斜体* を入れる**
```

太字と斜体は通常段落、見出し、表セル、タブ配置内の文字で使えます。リンク、画像、コードブロック、取消線、Markdownリストはβ版では解釈しません。

### 引用

```markdown
> 「本件契約は架空の例である。」
```

`>` で始まる1行を通常本文より1段下げます。

### 汎用表

先頭と末尾の `|` が必要です。2行目は3個以上の `-` で列定義を書きます。

```markdown
| 項目 | 中央 | 数量 |
| --- | :---: | ---: |
| 架空の項目 | **強調** | ２ |
```

- `---` は左揃え、`:---:` は中央揃え、`---:` は右揃えです。
- セル内改行は `<br>` です。
- セル内の `|` は `\|` と書きます。
- セル内で太字と斜体を使えます。

列幅を固定したいときは、表を `@表(列幅=...)` で囲みます。数値の単位は「12ptの全角文字が何字入る幅か」です。例えば `列幅=4,8,3` は48pt、96pt、36ptの3列を作ります。指定数と表の列数は一致させます。指定幅の合計が本文幅より狭くても拡大せず、表全体を左へ置いて右側を空けます。本文幅を超える指定も縮小しないため、各列幅の合計は本文幅内に収めてください。

```text
@表(列幅=8,16,4; 先頭行=中央) {
| 項目 | 内容 | 数量 |
| --- | --- | ---: |
| 架空 | 架空の内容 | ２ |
}
```

`先頭行=中央` を加えると、Markdown表の先頭行だけ全列を中央揃えにします。2行目以降は区切り行の `---`、`:---:`、`---:` に従います。先頭行は太字にはなりません。`先頭行=中央` と `列幅=` はセミコロンで区切り、順序はどちらでも構いません。

罫線もセル余白も付けず、通常本文と同じ文字サイズ・行送りで配置する表は `@罫線なし表` を使います。列幅も12pt文字単位です。列間には12pt全角文字1字分の間隔が入ります。Markdown上の1行目も、`先頭行=中央` を指定しない限り通常のデータ行として表示します。

```text
@罫線なし表(列幅=3,20,6) {
| １ | 訴状副本 | １通 |
| ---: | --- | ---: |
| ２ | 甲号証写し | 各２通 |
}
```

## 日本語Directive

Directiveは `@名前 {` の独立行で始め、`}` の独立行で閉じます。

### 配置

```text
@右揃え {
令和８年９月７日
}

@中央揃え {
以　上
}

@右配置 {
架空県架空市一丁目
架空法律事務所
弁護士　架空太郎
}

@右配置(3) {
原告訴訟代理人弁護士　架　空　太　郎
}
```

- `@右揃え` は本文幅全体で各行を右揃えにします。
- `@中央揃え` は各行を中央揃えにします。
- `@右配置` は左揃えの文字ブロック全体を右側へ置き、住所や代理人表示の左端を揃えます。
- `@右揃え(3)` や `@右配置(3)` の数値は、本文右端に空ける12pt文字の字数です。`3` は36ptを意味します。整数だけでなく小数も指定できます。
- `(印)`、`(職印)`、`(36pt)` のような単位・名称付き引数は使用できません。PDFへ印影自体は描画しません。

### 改ページ

```text
@改ページ
```

互換のため、独立行の `[改ページ]` と `【改ページ】` も受け付けます。

## 証拠説明書も汎用表で作る

法律文書固有の表種別や自動認識はありません。証拠説明書も `@表` を使い、列幅と先頭行の配置を原稿内で明示します。

```text
@表(列幅=4,8,3,6,6,10; 先頭行=中央) {
| 符号番号 | 標目 |  | 作成年月日 | 作成者 | 立証趣旨 |
| :---: | --- | :---: | :---: | --- | --- |
| 甲１ | 商品売買契約書 | 原本 | R8.4.1 | 原告及び被告 | 本件売買契約が成立したこと |
}
```

実際の書面と同じ順序で日付、裁判所名、代理人表示を書き、その後に汎用表を置きます。

```text
# 証拠説明書
@右揃え {
令和８年９月７日
}
架空地方裁判所民事部　御中
@右配置(3) {
原告訴訟代理人弁護士　架　空　太　郎
}
@表(列幅=4,8,3,6,6,10; 先頭行=中央) {
| 符号番号 | 標目 |  | 作成年月日 | 作成者 | 立証趣旨 |
| :---: | --- | :---: | :---: | --- | --- |
| 甲１ | 商品売買契約書 | 原本 | R8.4.1 | 原告及び被告 | 本件売買契約が成立したこと |
}
```

この例では先頭行だけが中央揃えです。データ行は区切り行の指定に従うため、`標目`、`作成者`、`立証趣旨` の列は左揃えになります。ページを跨ぐと先頭行を再表示し、ページ末に先頭行だけを残しません。

証拠意見書、証拠調べ請求書、証拠調請求書についても専用表・専用Directive・サンプルはありません。通常本文または汎用表として作成できます。

## 当事者目録と附属書類

当事者目録では、郵便番号を通常行として行頭から書き、続く行を `@タブ` で配置できます。タブ位置の単位も12pt文字の字数です。Directive内では実際のTab文字で欄を進めます。後ろのTabを書かなかった行は右端まで使えるため、代表者行は「役割欄と名称欄を結合した」場合と同じ配置になります。

```text
# 当事者目録
〒０００－００００　架空県架空市１丁目１番１号
@タブ(11,21) {
	原　告	株式会社架空商事
	上記代表者代表取締役　架　空　花　子
}
```

上の例では、最初のTabで左余白から11字目、次のTabで21字目へ移動します。代表者行にはTabが1個しかないため、11字目から右端までを一続きで使用します。これにより、全角空白を数えて揃える必要がありません。

附属書類は通常テキストでも罫線なし表でも作れます。次の例では、第1列の幅が1字で、その後に列間隔1字が入るため、番号と書類名の間隔が全角1字になります。

```text
@罫線なし表(列幅=1,5,15) {
| １ | 訴状副本 | １通 |
| --- | --- | ---: |
| ２ | 甲号証写し | 各２通 |
}
```

```text
１　訴状副本　　　　　　　　　１通
２　甲号証写し　　　　　　　各２通
```

## 法律文書の番号とインデント

番号部分は左へ出し、折返しは本文開始位置に揃えます。字下げの1単位は本文文字サイズです。

| 先頭パターン | 本文字下げ | 先頭行の戻し |
|---|---:|---:|
| `第１条` | 2 | 2 |
| `第１　` | 2 | 2 |
| `１　` | 2 | 1 |
| `１(1)　` | 3 | 2 |
| `(1)　` | 3 | 1 |
| `(1)ア　` | 4 | 2 |
| `ア　` | 4 | 1 |
| `ア(ア)　` | 5 | 2 |
| `(ア)　` | 5 | 1 |
| `(ア)ａ　` | 6 | 2 |
| `ａ　` | 6 | 1 |
| `ａ(a)　` | 7 | 2 |
| `(a)　` | 7 | 1 |

番号体系は先代KianPrintと同じです。外側の番号は全角数字、丸括弧は半角、丸括弧内の算用数字は半角で書きます。`（１）` のような全角括弧・全角数字は階層記号として扱いません。`第１条` または `第１　` で始まる段落が文書中にない場合は、各階層の本文字下げから1単位を引きます。`①`～`⑳` は直前段落より1段深くし、連続する丸数字は同じ深さにします。全角空白2字で始まる非空行は継続段落として、原則として直前段落の本文インデントを引き継ぎます。

## ページ分割とページ番号

- 本文は行送りを積み上げ、下余白に入る前に次ページへ送ります。
- 見出しと次の1行が入らないときは、見出しを次ページへ送ります。
- 表は行単位で分割し、罫線表は列名を再表示します。
- ページ番号は本文領域の横中央、下余白の縦中央に表示します。
- 1ページだけの文書では表示しません。複数ページまたは明示的改ページがあると全ページに表示します。

## 先代KianPrintの互換記法

行の両端に全角空白を置く旧式記法も読み込みます。新規文書ではMarkdown見出しと日本語Directiveを推奨します。

| 行頭 / 行末の全角空白 | 表示 |
|---|---|
| 5字 / 5字 | 中央、18pt |
| 4字 / 4字 | 中央、16pt |
| 3字 / 3字 | 中央、14pt |
| 2字 / 2字 | 中央、12pt |
| 2字 / 1字 | 右揃え、12pt |

## エラーと警告

- front matterの不正な数値、未知のプリセット、閉じる `---` や `}` の欠落は行番号付きエラーです。
- 未知の設定名は警告して無視します。
- エラーがある間も直前の正常なプレビューを残します。
- `プリセット: 裁判所` があると、プリセット以外の項目は評価されず無視されます。

## ビルドとテスト

必要環境はmacOS 13以降とXcodeです。外部パッケージへのネットワークアクセスは不要です。

```sh
xcodebuild -project KianPrint2.xcodeproj -scheme KianPrint2 \
  -configuration Release SYMROOT=$PWD/build build

cd Packages/KianPrintCore
swift test
```

出力は `build/Release/KianPrint2.app`、署名はad-hocです。詳細は [`Docs/Releasing.md`](Docs/Releasing.md) を参照してください。

## プライバシー

`Samples/` へ実事件資料を入れないでください。実在する当事者名、住所、電話番号、メールアドレス、事件番号、裁判所提出書面をコミットしないでください。研究用PDFは `ResearchDownloads/` に置くとGitから除外されます。
