# KianPrint2

KianPrint2は、プレーンテキストを日本の裁判・法律実務向けA4文書として組版するmacOSアプリです。原稿は `mi.app` などのテキストエディタで編集し、KianPrint2がライブプレビューとPDF出力を担当します。

β版は `0.2.0-beta.1` です。アプリの `CFBundleShortVersionString` は `0.2.0`、リリースタグは `v0.2.0-beta.1` です。

## 主な機能

- `.txt` をKian Markdown（Markdownの限定部分＋英語Directive）として解釈
- Core Textの実測幅と独自の日本語禁則処理で改行
- 裁判所プリセットの37字×26行組版
- 先代KianPrint互換の法律文書番号・ぶら下がりインデント
- 見出し、強調、引用、タブ配置、明示的改ページ
- 本文文字サイズ単位で列幅を指定できる汎用表
- 当事者目録などをスペースなしで配置できる、相対間隔指定のタブ位置
- 複数A4ページのベクタープレビューとPDF出力
- 保存の自動再読み込みと、エラー時の直前プレビュー保持

## 基本ワークフロー

1. Finderまたはmi.appで `.txt` を開きます。
2. mi.appのToolから保存してKianPrint2へ渡します。
3. 以後は保存するたびにプレビューが更新されます。
4. 必要なときに「PDFを書き出す」を実行します。

mi.appのToolには次の形式を利用できます。

```text
<<<SAVE DROP(KianPrint2.app)>>>
```

Markdown一般の `.md` を別のエディタに関連付けたまま使えるよう、入力拡張子は意図的に `.txt` としています。

## 書式設定と裁判所プリセット

設定はファイル先頭の `---` で囲んだfront matterに記載します。区切りはハイフン3個です。

### 37字×26行の発動条件

次のどちらかだけで裁判所プリセットが発動します。

1. front matterをまったく書かない（空のfront matterも同じ）。
2. `preset: court` を指定する。

```text
---
preset: court
---
```

裁判所プリセットがあると、同じブロックの他の項目は記載順にかかわらずすべて無視され、次の値に固定されます。

| 設定名 | 値 |
|---|---:|
| `paper` | A4（210×297mm） |
| `font` | Hiragino Mincho ProN W3 |
| `font-size` | 12pt |
| `top` | 35mm |
| `bottom` | 27mm |
| `left` | 30mm |
| `right` | 22mm |
| `kern` | 0pt |
| `spacing` | 13.62pt |
| `page-number` | on |
| `kinsoku` | court |

横は先代KianPrintと同じ余白由来の約447.87pt（37.323全角字相当）を使います。全角38字目は入らず、約0.323字分の余裕は半角文字や約物に使われます。縦は本文高を26等分し、大きな見出しも1行分の高さとして数えます。

値を手動ですべて同じにしても、`preset: court` がなければ37字×26行の制御は発動しません。見出しは文字サイズに応じた高さを使い、行数は保証されません。

```text
---
font-size: 12pt
top: 35mm
bottom: 27mm
left: 30mm
right: 22mm
kern: 0pt
spacing: 13.62pt
page-number: on
kinsoku: court
---
```

### 手動設定

front matterに一つでも設定があり、裁判所プリセットがない場合は手動書式です。書かなかった項目の初期値は裁判所書式と同じですが、37字×26行は保証されません。

| 設定名 | 形式 | 説明 |
|---|---|---|
| `paper` | `A4` | β版はA4のみ |
| `font` | フォント名 | macOSの本文フォント名 |
| `font-size` | `12pt` | 本文文字サイズ |
| `top` `bottom` `left` `right` | `20mm` | 各余白 |
| `kern` | `0pt` | 先代のKernに相当 |
| `spacing` | `6pt` | 文字サイズへ追加する間隔 |
| `page-number` | `on` / `off` | 複数ページ時の表示 |
| `kinsoku` | `court` | β版の日本語禁則規則 |

一般書面の例です。

```text
---
font-size: 12pt
kern: 0pt
spacing: 6pt
top: 25mm
bottom: 25mm
---
```

この行送りは12pt＋6pt＝18ptです。空行もこの文書の行送り1行分を占めます。繰り返し使う書式は、mi.appのToolにfront matterを定型文として登録すると便利です。

## 法律文書の原稿作法

本文では、段落と段落の間に空行を入れません。空行は実際の1行として組版されるので、原稿に書けばその分だけ縦位置が下がります。年、月、日、事件番号、金額、項番号、号証番号など、法律文書本文の数字は原則として全角で書きます。証拠説明書の表内の日付だけは実務上の例外として `R8.4.1` のように半角で書けます。

```text
第１　請求の原因
１　当事者
　　原告は、文房具の販売等を業とする株式会社である。
２　売買契約
　　原告と被告は、令和８年４月１日、売買契約を締結した。
```

## 対応するMarkdown記法

KianPrint2はMarkdown全体ではなく、次の記法だけを解釈します。

### 見出し

| 記法 | 裁判所プリセットでの表示 |
|---|---|
| `# 見出し` | 中央、18pt |
| `## 見出し` | 中央、16pt |
| `### 見出し` | 中央、14pt |
| `#### 見出し` | 中央、12pt |

`#`と見出し文の間に半角空白が必要です。サイズは先代KianPrintと同じく本文サイズに対する倍率で、順に1.5倍、4/3倍、7/6倍、1倍です。したがって本文が12ptなら18／16／14／12pt、本文が15ptなら22.5／20／17.5／15ptになります。

### 行内強調

```markdown
**太字**
*斜体*
**太字の中に *斜体* を入れる**
```

太字は本文フォントにかかわらずHiragino Sans W6で表示します。斜体は本文フォントのitalic traitを使います。見出しは太字化せず、本文と同じフォントのままサイズだけを変えます。太字と斜体は通常段落、見出し、表セル、タブ配置内の文字で使えます。リンク、画像、コードブロック、取消線、Markdownリストはβ版では解釈しません。

### 引用

```markdown
> 「本件契約は架空の例である。」
```

`>` で始まる1行を通常本文より1段下げます。

### 汎用表

先頭と末尾の `|` が必要です。2行目は3個以上の `-` で列定義を書きます。

```markdown
| 項目 | 中央 | 数量 |
| --- | :---: | ---: |
| 架空の項目 | **強調** | ２ |
```

- `---` は左揃え、`:---:` は中央揃え、`---:` は右揃えです。
- セル内の文字は左右の罫線から3pt離して配置します。
- セル内改行は `<br>` です。
- セル内の `|` は `\|` と書きます。
- セル内で太字と斜体を使えます。

列幅を固定したいときは、表を `@table(...)` で囲みます。数値の単位は `@tab` と同じで、1単位の実幅は本文の `font-size` と同じpt数です。例えば本文12ptの `@table(4,8,3)` は48pt、96pt、36pt、本文15ptなら60pt、120pt、45ptの3列を作ります。指定数と表の列数は一致させます。指定幅の合計が本文幅より狭くても拡大せず、表全体を左へ置いて右側を空けます。本文幅を超える指定も縮小しないため、各列幅の合計は本文幅内に収めてください。

```text
@table(8,16,4; center) {
| 項目 | 内容 | 数量 |
| --- | --- | ---: |
| 架空 | 架空の内容 | ２ |
}
```

`; center` を加えるとMarkdown表の先頭行だけ全列を中央揃えにし、`; right` なら全列を右揃えにします。2行目以降は区切り行の `---`、`:---:`、`---:` に従います。先頭行は太字にはなりません。配置指定は列幅の後にセミコロンで区切って書きます。

## Directive

ブロック型Directiveは `@name(...) {` の独立行で始め、`}` の独立行で閉じます。β版で使用できるDirectiveは `@tab`、`@table`、`@page` だけです。`@右配置`、`@右揃え`、`@中央揃え` は廃止しました。中央配置はMarkdown見出し、任意位置からの配置は `@tab` を使います。

### 改ページ

```text
@page
```

## 証拠説明書も汎用表で作る

法律文書固有の表種別や自動認識はありません。証拠説明書も `@table` を使い、列幅と先頭行の配置を原稿内で明示します。

```text
@table(4,8,3,6,6,10; center) {
| 符号番号 | 標目 |  | 作成年月日 | 作成者 | 立証趣旨 |
| :---: | --- | :---: | :---: | --- | --- |
| 甲１ | 商品売買契約書 | 原本 | R8.4.1 | 原告及び被告 | 本件売買契約が成立したこと |
}
```

実際の書面と同じ順序で日付、裁判所名、代理人表示を書き、その後に汎用表を置きます。

```text
# 証拠説明書
@tab(29.3) {
	令和８年９月７日
}
架空地方裁判所民事部　御中
@tab(16.3) {
	原告訴訟代理人弁護士　架　空　太　郎
}
@table(4,8,3,6,6,10; center) {
| 符号番号 | 標目 |  | 作成年月日 | 作成者 | 立証趣旨 |
| :---: | --- | :---: | :---: | --- | --- |
| 甲１ | 商品売買契約書 | 原本 | R8.4.1 | 原告及び被告 | 本件売買契約が成立したこと |
}
```

この例では先頭行だけが中央揃えです。データ行は区切り行の指定に従うため、`標目`、`作成者`、`立証趣旨` の列は左揃えになります。ページを跨ぐと先頭行を再表示し、ページ末に先頭行だけを残しません。

証拠意見書、証拠調べ請求書、証拠調請求書についても専用表・専用Directive・サンプルはありません。通常本文または汎用表として作成できます。

### タブ配置

`@tab` は、罫線のない複数欄を通常本文と同じ文字サイズ・行送りで配置します。引数はタブ位置そのものではなく、直前のタブ位置から次のタブ位置までの間隔です。1単位の実幅は本文の `font-size` と同じpt数、すなわち `12pt × (font-size / 12)` です。本文12ptなら1単位は12pt、本文15ptなら15ptになります。引数の個数に上限はありません。Directive内では実際のTab文字で、指定したタブ位置へ順番に進みます。1個目のTabは1個目の位置、2個目のTabは2個目の位置に対応し、文字が位置を越えていても自動的に次の位置へ飛ばしません。

```text
タブ　　位置　　　　です

@tab(4, 6) {
タブ	位置	です
}
```

本文12ptの場合、この2行は同じ位置に表示されます。最初のTabは行頭から4単位（48pt）、次のTabはそこから6単位（72pt）進むため、2番目のタブ位置は行頭から累計10単位です。小数も指定できます。連続するTab文字は空の欄を一つ挟み、各行の最後の欄は本文右端まで使えます。各欄の文字が次のタブ位置までに収まらなければ、その欄の開始位置に揃えて折り返します。折返しの最終行が1文字だけになる場合は、直前の文字も最終行へ送ります。指定した間隔の累計が本文幅を超えないようにしてください。

`@tab(2, 27, 1)` のように3個以上の間隔も指定できます。

```text
@tab(1, 7) {
	訴訟物の価額	１００万円
}
```

この例では、行頭のTabで1字目へ進み、「訴訟物の価額」の後のTabで累計8字目へ進みます。行頭のTabを書かず、1字幅の最初の欄へ「訴訟物の価額」を書けば、その文字は1字ずつ縦に折り返されます。タブ欄内の全角空白は削除せず、そのまま組版します。

## 当事者目録と附属書類

当事者目録では、郵便番号と住所、役割と名称をそれぞれTabで分けます。本文12ptの場合、次の例の `@tab(10, 11)` は、最初のTabを行頭から10単位、次のTabをその11単位後（行頭から累計21単位）の位置に置きます。

```text
# 当事者目録
@tab(10, 11) {
〒０００－００００	架空県架空市１丁目１番１号
	原　告	株式会社架空商事
	上記代表者代表取締役	架　空　花　子
}
```

これにより、郵便番号だけを左へ出し、住所を同じ位置に揃えられます。役職と氏名も別の欄なので、全角空白を数えて揃える必要がありません。役職が欄幅を超える場合は欄の開始位置に揃えて折り返し、最終行が1文字だけになるときは直前の文字も最終行へ送ります。

附属書類も `@tab` で配置します。次の例では番号の2字後、さらに27字後、さらに1字後にタブ位置があります。行内の連続したTabも意味があるため、削除しないでください。

```text
@tab(2, 27, 1) {
１	訴状副本		１通
２	甲号証写し	各２通
３	証拠説明書		２通
}
```

## 法律文書の番号とインデント

番号部分は左へ出し、折返しは本文開始位置に揃えます。字下げの1単位は本文文字サイズです。

| 先頭パターン | 本文字下げ | 先頭行の戻し |
|---|---:|---:|
| `第１条` | 2 | 2 |
| `第１　` | 2 | 2 |
| `１　` | 2 | 1 |
| `１(1)　` | 3 | 2 |
| `(1)　` | 3 | 1 |
| `(1)ア　` | 4 | 2 |
| `ア　` | 4 | 1 |
| `ア(ア)　` | 5 | 2 |
| `(ア)　` | 5 | 1 |
| `(ア)ａ　` | 6 | 2 |
| `ａ　` | 6 | 1 |
| `ａ(a)　` | 7 | 2 |
| `(a)　` | 7 | 1 |

番号体系は先代KianPrintと同じです。外側の番号は全角数字、丸括弧は半角、丸括弧内の算用数字は半角で書きます。`（１）` のような全角括弧・全角数字は階層記号として扱いません。`第１条` または `第１　` で始まる段落が文書中にない場合は、各階層の本文字下げから1単位を引きます。`①`～`⑳` は直前段落より1段深くし、連続する丸数字は同じ深さにします。全角空白2字で始まる非空行は継続段落として、原則として直前段落の本文インデントを引き継ぎます。

## ページ分割とページ番号

- 本文は行送りを積み上げ、下余白に入る前に次ページへ送ります。
- 見出しと次の1行が入らないときは、見出しを次ページへ送ります。
- 表は行単位で分割し、罫線表は列名を再表示します。
- ページ番号は本文領域の横中央、下余白の縦中央に表示します。
- 1ページだけの文書では表示しません。複数ページまたは明示的改ページがあると全ページに表示します。

## 先代KianPrintの互換記法

行の両端に全角空白を置く旧式記法も読み込みます。新規文書の中央配置にはMarkdown見出し、任意位置の配置には `@tab` を使います。特に、行頭に全角空白2字、行末に1字を置く `　　以上　` は後方互換のため引き続き右揃えとして扱います。

| 行頭 / 行末の全角空白 | 表示 |
|---|---|
| 5字 / 5字 | 中央、18pt |
| 4字 / 4字 | 中央、16pt |
| 3字 / 3字 | 中央、14pt |
| 2字 / 2字 | 中央、12pt |
| 2字 / 1字 | 右揃え、12pt |

## エラーと警告

- front matterの不正な数値、未知のプリセット、閉じる `---` や `}` の欠落は行番号付きエラーです。
- 未知の設定名は警告して無視します。
- エラーがある間も直前の正常なプレビューを残します。
- `preset: court` があると、preset以外の項目は評価されず無視されます。

## ビルドとテスト

必要環境はmacOS 13以降とXcodeです。外部パッケージへのネットワークアクセスは不要です。

```sh
xcodebuild -project KianPrint2.xcodeproj -scheme KianPrint2 \
  -configuration Release SYMROOT=$PWD/build build

cd Packages/KianPrintCore
swift test
```

出力は `build/Release/KianPrint2.app`、署名はad-hocです。詳細は [`Docs/Releasing.md`](Docs/Releasing.md) を参照してください。

## プライバシー

`Samples/` へ実事件資料を入れないでください。実在する当事者名、住所、電話番号、メールアドレス、事件番号、裁判所提出書面をコミットしないでください。研究用PDFは `ResearchDownloads/` に置くとGitから除外されます。
