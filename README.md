# KianPrint2

KianPrint2は、プレーンテキストを日本の裁判・法律実務向けA4文書として組版するmacOSアプリです。原稿は `mi.app` などのテキストエディタで編集し、KianPrint2がライブプレビューとPDF出力を担当します。

β版は `0.1.0-beta.1` です。アプリの `CFBundleShortVersionString` は `0.1.0`、リリースタグは `v0.1.0-beta.1` です。

## 主な機能

- `.txt` をKian Markdown（Markdownの限定部分＋日本語Directive）として解釈
- Core Textの実測幅と独自の日本語禁則処理で改行
- 裁判所プリセットの37字×26行組版
- 先代KianPrint互換の法律文書番号・ぶら下がりインデント
- 見出し、強調、引用、揃え、明示的改ページ
- 汎用表と証拠説明書、証拠調べ請求書／証拠調請求書、証拠意見書、附属書類、当事者目録
- 複数A4ページのベクタープレビューとPDF出力
- 保存の自動再読み込みと、エラー時の直前プレビュー保持

## 基本ワークフロー

1. Finderまたはmi.appで `.txt` を開きます。
2. mi.appのToolから保存してKianPrint2へ渡します。
3. 以後は保存するたびにプレビューが更新されます。
4. 必要なときに「PDFを書き出す」を実行します。

mi.appのToolには次の形式を利用できます。

```text
<<<SAVE DROP(KianPrint2.app)>>>
```

Markdown一般の `.md` を別のエディタに関連付けたまま使えるよう、入力拡張子は意図的に `.txt` としています。

## 書式設定と裁判所プリセット

設定はファイル先頭の `---` で囲んだfront matterに記載します。区切りはハイフン3個です。

### 37字×26行の発動条件

次のどちらかだけで裁判所プリセットが発動します。

1. front matterをまったく書かない（空のfront matterも同じ）。
2. `プリセット: 裁判所` を指定する。

```text
---
プリセット: 裁判所
---
```

裁判所プリセットがあると、同じブロックの他の項目は記載順にかかわらずすべて無視され、次の値に固定されます。

| 項目 | 値 |
|---|---:|
| 用紙 | A4（210×297mm） |
| フォント | Hiragino Mincho ProN W3 |
| 文字サイズ | 12pt |
| 上余白 | 35mm |
| 下余白 | 27mm |
| 左余白 | 30mm |
| 右余白 | 22mm |
| 字間（Kern） | 0pt |
| 行間（Line Spacing） | 13.62pt |
| ページ番号 | あり |
| 禁則処理 | 裁判所 |

横は先代KianPrintと同じ余白由来の約447.87pt（37.323全角字相当）を使います。全角38字目は入らず、約0.323字分の余裕は半角文字や約物に使われます。縦は本文高を26等分し、大きな見出しも1行分の高さとして数えます。

値を手動ですべて同じにしても、`プリセット: 裁判所` がなければ37字×26行の制御は発動しません。見出しは文字サイズに応じた高さを使い、行数は保証されません。

```text
---
文字サイズ: 12pt
上余白: 35mm
下余白: 27mm
左余白: 30mm
右余白: 22mm
字間: 0pt
行間: 13.62pt
ページ番号: あり
禁則処理: 裁判所
---
```

### 手動設定

front matterに一つでも設定があり、裁判所プリセットがない場合は手動書式です。書かなかった項目の初期値は裁判所書式と同じですが、37字×26行は保証されません。

| 設定名 | 形式 | 説明 |
|---|---|---|
| `用紙` | `A4` | β版はA4のみ |
| `フォント` | フォント名 | macOSのフォント名 |
| `文字サイズ` | `12pt` | 本文文字サイズ |
| `上余白` `下余白` `左余白` `右余白` | `20mm` | 各余白 |
| `字間` | `0pt` | 先代のKernに相当 |
| `行間` | `6pt` | 文字サイズへ追加する間隔 |
| `ページ番号` | `あり` / `なし` | 複数ページ時の表示 |
| `禁則処理` | `裁判所` | β版の日本語禁則規則 |

一般書面の例です。

```text
---
文字サイズ: 12pt
字間: 0pt
行間: 6pt
上余白: 25mm
下余白: 25mm
---
```

この行送りは12pt＋6pt＝18ptです。空行もこの文書の行送り1行分を占めます。繰り返し使う書式は、mi.appのToolにfront matterを定型文として登録すると便利です。

## 対応するMarkdown記法

KianPrint2はMarkdown全体ではなく、次の記法だけを解釈します。

### 見出し

| 記法 | 初期表示 |
|---|---|
| `# 見出し` | 中央、18pt |
| `## 見出し` | 中央、16pt |
| `### 見出し` | 中央、14pt |
| `#### 見出し` | 中央、12pt |

`#`と見出し文の間に半角空白が必要です。

### 行内強調

```markdown
**太字**
*斜体*
**太字の中に *斜体* を入れる**
```

太字と斜体は通常段落、見出し、表セル、事件情報の値で使えます。リンク、画像、コードブロック、取消線、Markdownリストはβ版では解釈しません。

### 引用

```markdown
> 「本件契約は架空の例である。」
```

`>` で始まる1行を通常本文より1段下げます。

### 汎用表

先頭と末尾の `|` が必要です。2行目は3個以上の `-` で列定義を書きます。

```markdown
| 項目 | 中央 | 数量 |
| --- | :---: | ---: |
| 架空の項目 | **強調** | 2 |
```

- `---` は左揃え、`:---:` は中央揃え、`---:` は右揃えです。
- セル内改行は `<br>` です。
- セル内の `|` は `\|` と書きます。
- セル内で太字と斜体を使えます。

## 日本語Directive

Directiveは `@名前 {` の独立行で始め、`}` の独立行で閉じます。

### 配置

```text
@右揃え {
令和8年9月7日
}

@中央揃え {
以　上
}

@右配置 {
架空県架空市一丁目
架空法律事務所
弁護士　架空太郎
}
```

- `@右揃え` は本文幅全体で各行を右揃えにします。
- `@中央揃え` は各行を中央揃えにします。
- `@右配置` は左揃えの文字ブロック全体を右側へ置き、住所や代理人表示の左端を揃えます。

### 改ページ

```text
@改ページ
```

互換のため、独立行の `[改ページ]` と `【改ページ】` も受け付けます。

### 事件情報

```text
@事件情報 {
当事者の表示: 別紙当事者目録記載のとおり
事件名: 架空代金請求事件
訴訟物の価額: 100万円
貼用印紙額: 架空の額
}
```

各行は `項目: 値` で書きます。`事件名` は独立行、その他は項目名と値を揃えて組版します。

## 表の意味指定と自動認識

表の種類は次の優先順位で決まります。

1. `@証拠説明書` などのDirectiveによる明示指定
2. 直前のMarkdown見出しの名前
3. 表の列名
4. いずれにも合わなければ汎用表

自動認識に依存したくない文書ではDirectiveを使ってください。

| 種類 | 明示Directive | 見出しでの認識 | 列名での認識 |
|---|---|---|---|
| 証拠説明書 | `@証拠説明書` | `証拠説明書` を含む | `号証` `標目` `立証趣旨` をすべて含む |
| 証拠調べ請求書 | `@証拠調べ請求書` / `@証拠調請求書` | 両方の表記に対応 | `立証趣旨` と、`証拠の標目` または `証人` |
| 証拠意見書 | `@証拠意見書` | `証拠意見書` を含む | `号証` `対象部分` `意見` をすべて含む |
| 附属書類 | `@附属書類` | `附属書類` を含む | `書類` `数量` を含む |
| 当事者目録 | `@当事者目録` | `当事者目録` を含む | `種別` `住所` `氏名・名称` を含む |

### 証拠説明書の明示指定

```text
@証拠説明書 {
| 号証 | 標目 | 作成年月日 | 作成者 | 立証趣旨 | 備考 |
| :---: | --- | :---: | --- | --- | --- |
| 甲1 | 架空の契約書 原本 | R8.4.1 | 架空商事 | 架空の契約成立事実 | |
}
```

見出しで自動認識させるなら、次のように書けます。

```markdown
# 証拠説明書

| 号証 | 標目 | 作成年月日 | 作成者 | 立証趣旨 | 備考 |
| :---: | --- | :---: | --- | --- | --- |
| 甲1 | 架空の契約書 原本 | R8.4.1 | 架空商事 | 架空の契約成立事実 | |
```

証拠説明書、証拠意見書と汎用表は罫線表で表示し、ページを跨ぐと列名を再表示します。証拠調べ請求書／証拠調請求書は横表を縦型レコードに変換します。附属書類は罫線なしの3列、当事者目録は罫線なしの縦型レコードです。具体例は [`Samples/`](Samples/) を参照してください。

## 法律文書の番号とインデント

番号部分は左へ出し、折返しは本文開始位置に揃えます。字下げの1単位は本文文字サイズです。

| 先頭パターン | 本文字下げ | 先頭行の戻し |
|---|---:|---:|
| `第１条` | 2 | 2 |
| `第１　` | 2 | 2 |
| `１　` | 2 | 1 |
| `１(1)　` | 3 | 2 |
| `(1)　` | 3 | 1 |
| `(1)ア　` | 4 | 2 |
| `ア　` | 4 | 1 |
| `ア(ア)　` | 5 | 2 |
| `(ア)　` | 5 | 1 |
| `(ア)ａ　` | 6 | 2 |
| `ａ　` | 6 | 1 |
| `ａ(a)　` | 7 | 2 |
| `(a)　` | 7 | 1 |

`第１条` または `第１　` で始まる段落が文書中にない場合は、各階層の本文字下げから1単位を引きます。`①`～`⑳` は直前段落より1段深くし、連続する丸数字は同じ深さにします。全角空白2字で始まる非空行は継続段落として、原則として直前段落の本文インデントを引き継ぎます。

## ページ分割とページ番号

- 本文は行送りを積み上げ、下余白に入る前に次ページへ送ります。
- 見出しと次の1行が入らないときは、見出しを次ページへ送ります。
- 表は行単位で分割し、罫線表は列名を再表示します。
- ページ番号は本文領域の横中央、下余白の縦中央に表示します。
- 1ページだけの文書では表示しません。複数ページまたは明示的改ページがあると全ページに表示します。

## 先代KianPrintの互換記法

行の両端に全角空白を置く旧式記法も読み込みます。新規文書ではMarkdown見出しと日本語Directiveを推奨します。

| 行頭 / 行末の全角空白 | 表示 |
|---|---|
| 5字 / 5字 | 中央、18pt |
| 4字 / 4字 | 中央、16pt |
| 3字 / 3字 | 中央、14pt |
| 2字 / 2字 | 中央、12pt |
| 2字 / 1字 | 右揃え、12pt |

## エラーと警告

- front matterの不正な数値、未知のプリセット、閉じる `---` や `}` の欠落は行番号付きエラーです。
- 未知の設定名は警告して無視します。
- エラーがある間も直前の正常なプレビューを残します。
- `プリセット: 裁判所` があると、プリセット以外の項目は評価されず無視されます。

## ビルドとテスト

必要環境はmacOS 13以降とXcodeです。外部パッケージへのネットワークアクセスは不要です。

```sh
xcodebuild -project KianPrint2.xcodeproj -scheme KianPrint2 \
  -configuration Release SYMROOT=$PWD/build build

cd Packages/KianPrintCore
swift test
```

出力は `build/Release/KianPrint2.app`、署名はad-hocです。詳細は [`Docs/Releasing.md`](Docs/Releasing.md) を参照してください。

## プライバシー

`Samples/` へ実事件資料を入れないでください。実在する当事者名、住所、電話番号、メールアドレス、事件番号、裁判所提出書面をコミットしないでください。研究用PDFは `ResearchDownloads/` に置くとGitから除外されます。
